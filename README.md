# InzOpr-MDzie-ASlu
Tytuł projektu: Regnum  
Zespół: Michał Dziekoński 180586, Aleksander Ślusarczyk 168585  
Idea i problem: Stworzenie wtyczki do przeglądarki umożliwiającej polecanie na podstawie wyszukiwań użytkownika artykułów zbliżonych do przeglądanych przez użytkownika  
Użytkownicy i scenariusz: Osoba przeglądająca Wikipedię po użyciu wtyczki dostaje listę artykułów zbliżoną tagami do wcześniej wyszukiwanych
Zakres funkcjonalny: Wtyczka pobiera historię wyszukiwań, znajduje wyszukania związane z artykułami na Wikipedii, Z znalezionych artykułów wyciąga tagi,
na podstawie znalezionych tagów znajduje artykuły z jak najbardziej zbliżonymi, na oddzielnej stronie wyświetla artykuły z najlepszymi dopasowaniami
